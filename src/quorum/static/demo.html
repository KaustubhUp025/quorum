🧭 What happens next

Does Quorum stop when an MR is blocked? No — "blocked" only marks the merge as unsafe. Quorum still posts every finding and opens a draft fix MR for each critical bug. Merge a fix MR and the Cloud Run webhook automatically re-reviews the branch — so it's a loop: detect → fix MR → re-review → unblock.
